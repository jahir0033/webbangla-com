# WebBangla Technologies Website

React + Vite + Tailwind CSS + DaisyUI single-page corporate website.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Main sections
Home, About, Services, Why Us, Contact.
